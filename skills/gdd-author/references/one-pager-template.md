# One-Pager GDD Template (Game Jam, ≤ 200 行)

适用场景: 48h Game jam, 内部快速对齐, 1 页纸 / 1 个 markdown 文件就能讲完。

## 1. 整页示例

```markdown
---
title: <游戏名> - Game Jam GDD
type: gdd-jam
version: 0.1
synced: <YYYY-MM-DD>
status: 草稿
tags: [<genre>, jam, <platform>]
---

# 《<游戏名>》Game Jam 设计稿

## 1. 一句话 + 核心循环
> <一句话定位, ≤ 30 字>

```
<ASCII 流程图, 1 个核心循环>
例: 移动 → 收集 → 合成 → 战斗 → 升级 → 移动
```

## 2. 主要操作 (≤ 3 个)
| 操作 | 输入 | 响应 | 失败态 |
|---|---|---|---|
| 移动 | WASD | 角色移动 + 物理碰撞 | 撞墙停 |
| 攻击 | 鼠标左键 | 短距挥砍 + 命中粒子 | 无目标, 出硬直 |
| 技能 | Space | 3 秒冲刺 + 无敌 | 冷却 5 秒 |

## 3. Scope
### 3.1 IN (做)
- <2-4 个特性, 每条 1 行>

### 3.2 OUT (不做) — 硬性闸门
- 多人 / 存档 / 教程 / 多个 boss / 剧情
- <其他主动放弃的特性, 至少 3 条>

## 4. 时间盒
- 0-12h: 核心循环可玩
- 12-32h: 内容 + 美术
- 32-48h: 测试 + 提交
```

## 2. 填写要点

- **核心循环** 必须有 ASCII 流程图, 不能光写文字。
- **主要操作 ≤ 3 个** — 多于 3 个说明没想清楚核心循环, 删到 3 个。
- **Scope OUT 至少 3 条** — jam 文档最容易死在这里, 别忘了写。
- **时间盒用小时数**, 不用日期, 48h 内不用算 "Week 1 / Week 2"。

## 3. 何时升级到 Lean GDD

jam 提交后, 你发现想接着做 → 用 `lean-gdd-template.md` 重写, 不要就地扩展。
