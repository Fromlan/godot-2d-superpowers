# 2D Godot 项目指令

你正在一个 **2D Godot** 游戏项目中工作。本文件是**给独立游戏项目用的模板**；复制 `example-game/` 时请一并带走，并按自己的游戏改写「本项目」与「关键约定」。

## 技能调度

**已安装 `godot-2d-superpowers`**（插件，或技能目录可访问）：

1. 先读 `using-game-dev`，查决策表，再行动。
2. 多技能命中时：**流程类优先于知识类**。
3. 用户显式说「这次跳过 X」才可跳过流程检查点，并在回复里记录。

**未安装技能包**：

- 不要虚构技能调用，不要硬套决策表。
- 仍遵守下方「关键约定」；设计/实现/调试问题按项目结构直接处理。

技能包位置（按实际情况择一）：

- 插件安装：由 agent 技能系统加载，无需路径
- 本地克隆：通常在仓库根的 `skills/`，入口为 `skills/using-game-dev/SKILL.md`
- 你自己的 Godot 项目：`.mimocode/skills/` 或全局插件

## 本项目

| 项 | 值 |
|----|-----|
| 引擎 | Godot 4.7 |
| 类型 | 2D 平台跳跃（示例，可替换） |
| 项目根 | 本 `AGENTS.md` 所在目录（含 `project.godot`） |
| 样例来源 | godot-2d-superpowers `example-game/` |

| 目录 | 用途 |
|------|------|
| `scenes/` | 场景（`.tscn`） |
| `scripts/` | GDScript |
| `assets/` | 精灵 / 音频 / 字体；换素材时遵守命名与导入约定 |
| `tests/` | GUT 测试（逻辑层优先） |
| `addons/` | 编辑器插件（如 GUT；本模板不预装） |

## 测试

逻辑层（纯函数、公式、状态机）改动应有对应测试。

```powershell
# 在技能包仓库根（若使用官方 scripts）
.\scripts\run-tests.ps1

# 或在本项目用 Godot 无头模式跑 GUT（需已装 addons/gut）
```

未装 GUT 时：先说明缺依赖，再改代码；不要假装测试已跑。至少用 `godot --headless --quit` 做脚本解析冒烟，并在回复里写明「逻辑层测试未执行」。

## 关键约定（与技能包一致，未装技能时仍适用）

- **实现前**：大改动先拆成小任务再写；小修可直接改，但不要跳过「先看相关文件」。
- **逻辑 vs 装配**：手感/数值抽成可测纯函数；节点组装用集成或手动验证。
- **资源**：加图/音效先落 `assets/` 对应子目录，命名可追溯，不把临时文件塞进版本库。
- **关卡**：关卡数据与场景组合分离，避免把数值写死在多处场景里。
- **调试**：报 bug 先复现与定位根因，再改；不要「改一点试试」。
- **范围**：本项目只做 2D；3D / 其他引擎需求应先告知用户本套件不适用。

## 不做的事

- 不覆盖用户未要求的重构与「顺手优化」
- 不提交、不发布，除非用户明确要求
- 不在未确认的情况下改 `project.godot` 的 InputMap、autoload、渲染后端

## 用户指令优先

用户直接要求 > 本文件 > 技能默认流程。与技能冲突时，以用户显式覆盖为准并说明。
