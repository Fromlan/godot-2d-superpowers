# Sprites

Drop your `.png` / `.svg` files here, following `skill:asset-pipeline` naming:

- `player_idle.png` / `player_run.png` / `player_jump.png`
- `enemy_<type>.png`
- `tile_grass.png` / `tile_stone.png`
- `icon_heart.png` (UI)

The example uses programmatic shapes (ColorRect) and a placeholder SVG so the project runs without any external art.

## Free 2D asset sources

- [Kenney.nl](https://kenney.nl/) — CC0
- [OpenGameArt.org](https://opengameart.org/) — various (check each)
- [Itch.io asset packs](https://itch.io/game-assets/free) — various

Always check license, especially for "redistribution" rights if you plan to release commercially.
